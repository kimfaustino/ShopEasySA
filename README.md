# ShopEasySA: Consumer-to-Consumer (C2C) E-Commerce Platform

## Overview

ShopEasySA is a Consumer-to-Consumer (C2C) e-commerce platform developed as part of the **ITECA3-12 Web Development and E-Commerce** module.

The platform allows South African users to register, list products for sale, browse products, and purchase items securely. An administrator portal provides management functionality through Role-Based Access Control (RBAC)

# Installation

If you want to run ShopEasySA locally for development or testing:

1. Download the repository.
2. Import 'database/shopeasysa' into MySQL using phpMyAdmin.
3. Update 'config.php' with your local database credentials.
4. Place the project files in your servers 'htdocs' directory (XAMMP).
5. Access the site through 'http://localhost/ShopEasySA'.

or visit the hosted website.
